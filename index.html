The problem

Typing while you teach doesn't work.

You're mid-sentence with a student, and you notice the same mistake they made last week. Do you stop to write it down? Try to remember it for later? Most tutors just let it go — and the pattern never gets addressed.

ChatterCheck was built to fix exactly that: it listens, builds the transcript for you, and only surfaces something once it's actually worth your attention — a mistake that's repeated, not a one-off slip.

I built this for my own Preply lessons because I needed it myself. It's currently in beta — early users get a say in what we build next.

What it does

Everything a tutor actually needs, nothing you don't

01

Live transcript, zero typing

Turn on recording and just teach. The transcript builds itself in the background using your browser's built-in speech recognition.

02

Flags only what repeats

A slip doesn't interrupt you. A pattern does. Mistakes only surface once they've actually happened more than once.

03

A file per student

Progression chart, corrections with context, and a vocabulary glossary — split into idioms, phrasal verbs, collocations and metaphors — all built automatically.

04

Review on your own time

Nothing forces you to tag mistakes mid-lesson. Come back to it that evening, or next week — the transcript keeps.

05

Students practice on their own

A simplified link — no login, no install — where students review their glossary and drill it with built-in flashcards.

06

Private by design

No server, no student accounts, no data anyone else can see. Everything lives in the browser it was created in.

Questions

Before you ask

Is this affiliated with Preply?
No — it's an independent tool built by a tutor. It runs alongside any video call, Preply included, but it isn't made or endorsed by Preply.
Is my students' data safe?
It never leaves the browser it's created in — there's no server storing it, and no account required to use it. You're responsible for letting students know if a session is being recorded, same as with any recording tool.
What do I need to run it?
Any modern browser works for reviewing files and tracking progress. Live recording currently needs Chrome, since it uses Chrome's built-in speech recognition.
Do my students need to sign up for anything?
No. They open a link — no account, no install, no login, ever.
What happens after I join early access?
You'll hear back directly to get set up, and get a say in what gets built next before it locks in as a paid product.
